# React Frontend Development

Follow this process:

1. Inspect the existing React application.
2. Review API_DOCUMENTATION.md.
3. Use functional React components.
4. Use React Router.
5. Use Axios for API communication.
6. Centralize API configuration.
7. Create reusable UI components.
8. Implement loading and error states.
9. Implement form validation.
10. Protect restricted pages.
11. Use responsive layouts.
12. Run tests and production builds.

Do not:

- Connect directly to PostgreSQL.
- Hardcode API responses.
- Duplicate API logic.
- Place backend business logic in React.

Report modified files and build results.
