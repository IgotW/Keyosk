# Laravel API Development

Follow this process:

1. Inspect the Laravel version and installed packages.
2. Read the relevant system requirements.
3. Inspect existing routes, models, and migrations.
4. Use Laravel REST API conventions.
5. Use Form Requests for validation.
6. Use Eloquent ORM for database operations.
7. Use API Resources for consistent responses.
8. Use policies or middleware for authorization.
9. Use service classes for complex business logic.
10. Use transactions for order creation.
11. Write feature tests.
12. Run tests and fix failures.

Security:

- Never expose passwords.
- Validate all requests.
- Enforce role permissions.
- Prevent customers from accessing other orders.
- Never trust frontend validation.

Report all modified files and test results.
